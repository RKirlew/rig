Open a Socket: Create a UDP socket on your local machine.Craft a Binary Message: The message must follow a specific DNS header format, including a Transaction ID, Flags (e.g., recursive query), and the Question (domain name and record type like 'A' or 'MX').Send and Receive: Send the packet to the server's IP (e.g., Google Public DNS at 8.8.8.8) and wait for the binary response.Parse Response: Convert the binary data back into a readable format to find the IP address or error code.
